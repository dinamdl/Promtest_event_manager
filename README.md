# Prom-Test միջոցառումներ

Միջոցառումների կառավարման պարզ ծրագիր՝ HTML + CSS + JavaScript, առանց գրադարանների։

## Ֆայլեր
- `index.html` — էջի կառուցվածքը
- `style.css` — ոճերը (բաց և մուգ թեմա)
- `app.js` — ամբողջ տրամաբանությունը (ցանկ, ֆիլտրեր, ձև, CSV ներմուծում/արտահանում)
- `data.js` — սկզբնական 6 միջոցառումները Google Sheets-ից

## Ինչպես բացել VS Code-ում
1. VS Code → File → Open Folder → ընտրել այս թղթապանակը
2. Տեղադրել **Live Server** ընդլայնումը (Ritwick Dey)
3. Աջ սեղմել `index.html` → **Open with Live Server**

Կամ պարզապես կրկնակի սեղմել `index.html`-ի վրա։

## Տվյալներ
Տվյալները պահվում են բրաուզերի `localStorage`-ում (բանալի՝ `promtest-events-v1`)։
Սկզբնական տվյալները նորից բեռնելու համար՝ DevTools → Application → Local Storage → ջնջել այդ բանալին։
